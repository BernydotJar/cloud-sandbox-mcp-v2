Qué se instala
- Una extensión local MV3 de Edge, ID ecamjbhjlcacmchoebdligpmhcebdgci.
- Acceso para leer/modificar únicamente https://teams.cloud.microsoft/*.
- nativeMessaging para comunicarse con el backend local de Sandbox.
- storage para un identificador aleatorio de esta instalación/perfil.
- Un host Native Messaging registrado solo en Microsoft Edge y solo para ese ID.
- Un socket Unix privado; no abre nuevos puertos ni requiere Remote Debugging.
- Un parche aditivo al bridge Mac; conserva herramientas, sesiones, orígenes y AX.

Alcance del perfil
Cargar la extensión únicamente en la ventana Toyota, perfil Work11. La extensión
y la sesión Teams permanecen en Edge. El backend empareja un identificador local
con ese perfil; otro perfil/incógnito se rechaza. El identificador NO demuestra
la identidad Toyota: antes de cualquier escritura se comprueba cuenta/destinatario.
No se transfieren cookies, contraseñas ni sesiones a Linux.

Permisos que se revisan en Edge
nativeMessaging, storage y https://teams.cloud.microsoft/*.
La extensión puede leer y modificar Teams en las pestañas de este perfil.
No solicita cookies, history, debugger, tabs global ni acceso a otros sitios.
Para cargar el paquete local se usa Developer Mode de extensiones; esto NO activa
Remote Debugging. Si una política corporativa lo impide, no se modifica la política.

Instalación
1. install-on-mac.mjs --inspect verifica hashes, bridge exacto y ausencia de grant.
2. --install escribe archivos propios, crea un secreto local privado y recarga
   únicamente com.lch.cloud-sandbox.computer-use. No reinicia Edge, AX ni Docker.
3. En edge://extensions del perfil Toyota: Load Unpacked y seleccionar
   ~/Library/Application Support/LCH/SandboxDOM/extension.
4. Si la pestaña Teams ya estaba abierta, recargarla una vez para cargar el
   content script, tras verificar que no hay datos pendientes de guardar.

Reversión
--rollback exige bridge y archivos propios sin cambios y ningún grant activo.
Restaura el bridge previo, retira los archivos conocidos y recarga solo el bridge.
Después se descarga/elimina la extensión en el perfil Toyota y se puede apagar
Developer Mode si estaba desactivado antes. Archivos desconocidos se conservan.
No se cambia el controlador MCP ni se publica código remoto.
